JavaScript Basics

    Declaring Variables
        - use 'let' for values that change
            let x = 0;
                - you can still change it later on by doing something like: 
                    x = 10;
        - use 'const' for values that stay the same 
            const y = 20;
                - can't change it anymire, and if you try to change it, you'll get an error
    
    Variable Naming
        Rules:
            - start with letter, _, or $
            - no spaces or special characters
            - case sensitive (myVar is NOT myvar)
        Conventions: 
            - camelCase for variables
                ex. 
                userName, totalScore
            - UPPER_CASE for constants
                ex. MAX_SIZE, API_KEY
    
Data Types

    Primitive Types:
        - String (words/names)
        - Number (integers and decimals)
        - Boolean (true/false)
        - Undefined (no value assigned)
        - Null (intentionally empty)
    Checking Types: 
        - use 'typeof' tp check what type a value is (arrays return 'object')

Arithmetic Operators

Comparison Operators
