- for colors, you can use color names in regular english or hex codes
- can find different font options by going to "fonts.google.com"
    - copy the code to html 
- the box model: 
    - every element is a box
    - the border is the edge and can be made bigger by increasing the pixels 
    - the box model shows you how much space is being taken
