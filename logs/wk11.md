# APIs

It has to do with channeling between two programs. 

API = Application Programing Interface

- It's a way for programs to talk to each other 

    Restaurant Example

How APIs Work

    1. You request data
    2. Server processes request
    3. Server responds with data (usually JSON)

JSON = JavScript Object Notation. A text format for data

    - the keys have to be in double quotes (")
    - the values can be strings, numbers, booleans, arrays, objects, "null"
